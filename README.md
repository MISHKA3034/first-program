# 🍔 Student Food Finder

Простое веб-приложение для студентов Пинска: помогает найти, где недорого поесть.

**Сайт:** https://mishka3034.github.io/first-program/

## Что умеет
1. **Поиск** по названию, блюду или типу кухни («шаурма», «пицца», «Ленина»).
2. **Фильтр по бюджету:** До 7 / До 15 / До 30 BYN.
3. **Карточки заведений:** адрес, блюда и цены, ссылка на источник данных.

## Как работает фильтр по бюджету
Заведение показывается, если в нём есть **хотя бы одно блюдо** не дороже выбранного бюджета.
В карточке остаются только блюда, которые вписываются в бюджет.

## Как устроено
Файл `index.html` и папка `img/` с фото блюд (фото для примера, с Wikimedia Commons; авторы указаны внизу страницы).

В `index.html`:
- **HTML** — структура страницы (заголовок, поиск, кнопки);
- **CSS** — внешний вид (цвета, карточки, вид на телефоне);
- **JavaScript** — список заведений (`places`) и логика поиска и фильтра.

Сервера и базы данных нет: все данные лежат прямо в файле.

## Как добавить заведение
Открыть `index.html`, найти `const places = [`, скопировать любой блок `{ ... },` и поменять название, адрес, блюда и цены.

## Источники данных
Яндекс Карты, Clever.by, Just-eat.by, 2ГИС, Slivki.by, Tripadvisor, p-v.by, pinskmedia.by (ссылка — в каждой карточке).
Цены ориентировочные, проверены в ноябре 2026 года.
